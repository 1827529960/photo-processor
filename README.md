# 证件照批量处理工具

> ⚠️ **卸载说明**：本软件运行时会在用户主目录下生成 `.photo_processor` 文件夹（包含配置文件和日志文件）。卸载软件时，请同时删除该文件夹：
> - Windows: `C:\Users\用户名\.photo_processor`
> - macOS/Linux: `~/.photo_processor`

一个简单易用的证件照批量处理工具，支持像素缩放、文件大小限制、格式转换等功能。

## 功能特点

- **批量处理**：支持同时处理多张图片
- **精确压缩**：使用二分查找算法，精确匹配目标文件大小
- **证件照预设**：内置一寸、二寸、小二寸等常用证件照规格
- **格式转换**：支持 JPG、PNG、BMP 格式互转
- **智能裁剪**：按比例裁剪到目标尺寸
- **EXIF处理**：可选择移除图片元数据

## 安装依赖

```bash
pip install Pillow
```

## 使用方法

### 直接运行

```bash
python photo_processor.py
```

### 打包为可执行文件

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "证件照处理工具" photo_processor.py
```

打包后的可执行文件位于 `dist` 目录。

## 功能说明

### 常用预设

| 预设名称 | 尺寸（像素） | 目标大小 |
|---------|-------------|---------|
| 一寸证件照 | 295×413 | 100KB |
| 二寸证件照 | 413×579 | 150KB |
| 小二寸证件照 | 413×531 | 120KB |
| 五寸照片 | 1050×1500 | 2MB |
| 网络头像 | 400×400 | 200KB |

### 参数设置

- **目标大小**：压缩后的文件大小（支持 KB/MB）
- **最大宽度/高度**：缩放时的最大尺寸限制
- **固定宽度/高度**：证件照的精确尺寸
- **启用裁剪**：按比例裁剪到目标尺寸
- **最低画质**：压缩时的最低画质（1-100）
- **DPI**：输出图片的分辨率

### 输出设置

- **输出格式**：保持原格式或转换为 JPG/PNG/BMP
- **同名文件**：覆盖、重命名或跳过
- **移除EXIF**：删除图片的元数据信息
- **保留文件名**：保持原文件名不变

## 使用流程

1. 点击"选择文件"或"选择文件夹"选择要处理的图片
2. 在"常用预设"中点击对应按钮，自动填充证件照参数
3. 根据需要调整其他参数
4. 点击"开始处理"
5. 处理完成后，点击"打开输出文件夹"查看结果

## 注意事项

- 支持的图片格式：JPG、JPEG、PNG、BMP
- 压缩到目标大小时，非 JPEG 格式会自动转换为 JPEG
- 建议先用少量图片测试参数效果
- 首次运行会弹出使用说明，可在"帮助"菜单中再次查看

## 运行时文件

软件运行时会在用户主目录下生成 `.photo_processor` 文件夹，包含以下文件：

| 文件 | 说明 |
|------|------|
| `config.json` | 配置文件（启动提示、历史记录等） |
| `photo_processor.log` | 运行日志文件 |

**文件位置**：
- Windows: `C:\Users\用户名\.photo_processor\`
- macOS/Linux: `~/.photo_processor/`

**重要提示**：卸载软件时，请同时删除该文件夹以完全清理软件数据。
